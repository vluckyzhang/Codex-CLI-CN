Codex-CLI-CN / 0.120.0

给新版 Codex CLI 的一层稳妥中文外壳

基于原项目 codex-Chinese 的思路重做， 面向 @openai/codex 0.120.0 的实际包结构进行了重新适配。 它先自动备份原始启动器，再注入中文兼容层，优先覆盖帮助页、子命令帮助页与共享说明文本。

查看仓库 查看原项目 
npm install -g @openai/codex@0.120.0
git clone https://github.com/vluckyzhang/Codex-CLI-CN.git
cd Codex-CLI-CN
npm run inject
codex --help

为什么要重做

0.120.0 已经不是旧版纯脚本结构，而是“Node 启动器 + 原生二进制”架构。旧版 0.40.0 的注入方式无法直接复用。

本项目的取舍

不直接碰 codex.exe，而是把变更限定在启动器层。这样回退更简单，升级风险也更可控。

当前覆盖范围

帮助页翻译

覆盖 codex --help、codex help ... 与多组子命令帮助说明。

自动备份

注入前会先备份原始 bin/codex.js，恢复时可直接回到官方启动器。

透明运行

交互式 TUI 默认不被拦截，尽量保留官方终端行为与兼容性。

兼容性说明：由于官方 0.120.0 核心已经是原生二进制，交互式主界面目前保持英文，以避免破坏真实终端能力。

技术路线

这次适配不是把旧脚本简单“搬过去”，而是重新围绕新版包结构设计了一套更轻量的补丁流程：

  • 自动解析全局 npm 安装目录或自定义目标目录。
  • 校验版本，默认只对 0.120.0 注入。
  • 写入中文启动器与翻译表，同时保留原始备份。
  • 仅在帮助页等安全场景下进行文本替换。
