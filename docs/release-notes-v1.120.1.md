# v1.120.1 更新说明

这次更新重点解决了 Windows GUI 的可用性问题，并补齐了安装路径探测、管理员权限启动和更完整的中文覆盖。

## 新增内容

- 新增“检测安装路径”能力，会综合 `where codex`、`npm root -g`、`npm prefix -g` 与常见全局安装目录自动定位真实安装位置。
- 新增 `locate` 命令，方便在命令行中直接查看当前系统上可用的 Codex 安装目录候选。
- 新增项目介绍页图片素材与更醒目的 Emoji 视觉元素。

## 修复与改进

- 修复 GUI 中“使用默认路径”无反应的问题。
- 修复 GUI 环境检查在 Windows 图形进程下闪出黑窗后无响应的问题。
- 修复 GUI 后台线程直接访问界面状态导致的检测失败问题。
- GUI 默认请求管理员权限启动，减少权限不足造成的补丁写入失败。
- 将帮助页之外的登录提示、常用状态输出与共享说明文本纳入更大范围的中文处理。
- 保持对 `@openai/codex 0.120.0` 的兼容目标不变。

## 发行包

- `Codex-CLI-CN-v1.120.1-GUI-win64.zip`
  - 包含 `Codex-CLI-CN-GUI.exe`
  - 包含 `README.md`、`NOTICE.md`、`CHANGELOG.md`、`发行说明-v1.120.1.md`、`LICENSE`

## 说明

由于 `@openai/codex 0.120.0` 的交互式主界面核心仍是官方原生二进制 TUI，本版本继续优先扩大“帮助页 / 登录提示 / 状态输出 / 共用说明文本”的中文覆盖范围，并通过启动前提示与 GUI 工具改善整体中文使用体验。
